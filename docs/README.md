维护规则：

- 先记录目标和实际证据，再标记完成；明确区分静态核查、自动测试、真实宿主操作和模型实际回答。
- 修改产品流程时更新改造计划与验收项；修改宿主接入方式时更新 Windows 开发说明。
- 每轮交付更新维护记录，写明未通过、未执行和遗留问题。
- 不在仓库提交账号、令牌、真实聊天记录、用户论文或完整日用 profile；测试使用合成样本。
- `release/` 是被忽略的本地操作目录，不能作为其他机器或公开发布已验证的证据。
