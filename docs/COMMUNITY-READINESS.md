## 建议完善，避免扩大主界面

- **历史清理**：为失效记录提供“移除历史”，明确只移除记录，不删除文件或对话；避免加入书架、阅读状态等已取消的管理功能。
- **文件辨识**：同名文件显示足以区分的来源/会话，减少当前会话文件列表中的重复或歧义；记录很多时不挤压“粘贴文字”等入口。
- **操作反馈**：保存、打开、失败和重试状态清楚；未保存内容在关闭或切换前有合理提示。至少验证键盘、长文件名及较窄窗口。
- **持续验证**：CI 增加 Windows 检查，保留现有 Linux 检查；针对跨会话与失败恢复补有意义的集成验证。
- **问题反馈**：提供包含 DSH/插件版本、复现步骤及脱敏截图的 Issue 模板，提醒不上传账号、原始聊天和私人文档。
