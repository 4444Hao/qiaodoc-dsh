# 对话文档与历史面板

更新日期：2026-11-01。当前工作区修复候选 `1.2.0-dev.3`，固定基线及日用安装仍为 dev.2。精简改造与粘贴原文已完成；本轮补首次滚动修复和发行资料，101 项自动测试、13 项隔离浏览器回归通过。专项结果与未覆盖项以 [阶段验收报告](ACCEPTANCE-REPORT.md) 为准。

## 当前产品约定

唯一主流程：**原生对话 → 打开文件 → 阅读与选段交互 → 历史返回原会话**。

保留已基本实现的左侧原生聊天、右侧原文、独立滚动与选段解释/翻译/复制/询问 AI。本轮只补历史索引与返回定位，不另建聊天 UI、不改变任务发送保护。

旧计划中的“从书籍创建/继续讨论”“双入口统一阅读器”“书籍管理与显示改名”不再作为本轮交付目标。会话由用户在 DSH 中管理；插件只返回已有会话。失效目标提示，不静默新建。

## 主界面减法

| 原界面 | 本轮处理 |
| --- | --- |
| 乔木阅读入口 | 改为“文档历史” |
| 书库、封面、作者、阅读状态筛选 | 主面板移除 |
| 找书、示例书、导入书籍 | 主面板移除，不自动加入历史 |
| 独立伴读、从书籍新建会话 | 客户端不再注册或引用这条路径 |
| 朗读、生词本、Anki 等入口 | 主面板移除；旧源码和数据暂保留 |
| 原生对话内文件阅读 | 行为保留；被动记录打开、位置与交互锚点 |

历史面板只按实际存在的格式分组，每行显示文件名、对应会话与最近打开时间。没有独立导入或新建讨论按钮。当前格式为 PDF/TXT/Markdown/HTML；本轮不新增 EPUB 渲染。

## 数据规则

- 成功在原生文档预览中打开后才登记，失败打开或单纯上传不登记。
- 一条历史对应 `sessionId + 规范化来源路径`。同一来源在同一会话更新原记录；不同会话分别记录。已导入副本沿用现有内容 ID；不同来源路径暂不做内容合并。
- 历史保存于宿主原书库根下的独立 `document-history.json`，版本为 1。不把旧 library/state 文件改成新 schema，不删除或自动迁移旧条目。
- 记录原文页码与页内偏移，非 PDF 使用相对滚动位置；聊天位置分别保存原生节点 key、事件 seq 与轮次。
- 解释/翻译或用户最终发送带引用的问题后，记录对应用户消息位置。“询问 AI”插入草稿不等于已发送，不提前写入虚构消息锚点。
- 历史写入串行、原子落盘。损坏索引保留原文件并报错，不降级为空后覆盖。
- 从本轮开始登记；不遍历历史会话推断旧打开行为，也不把无关联的旧书库混入新面板。

## 返回导航

先确认已有会话和文件可用，再通过 `uiWorkspace.openSession` 导航，等待该会话挂载后打开原生右栏。PDF 渲染后恢复保存的位置，尊重恢复期间用户的主动滚动。消息有锚点时用 Session `loadThrough(seq)` 加载历史，再按聊天节点定位；不复制原生聊天渲染器。

会话切换、插件卸载或用户继续操作时，过期恢复不能操作其他会话。原文与消息位置分别验收；找不到精确消息时明确提示，保留已打开的正确会话和文档。原生 DOM 属性适配仅核查 rc.5，其他 rc 版本不因原包 engines 声明而视为通过。

## 追加：粘贴原文（1.2.0-dev.2）

在现有打开入口展开粘贴表单，提供内容、文件名、TXT/Markdown 和“保存并打开”。从首个非空行生成名称，允许保存前修改；不增加富文本编辑器或 AI 处理。宿主从已有会话的持久化 header 读取 cwd，写入其 `粘贴文档/` 子目录，UTF-8、2 MiB 上限，独占创建避免覆盖。客户端不能指定保存目录。

打开成功后复用文档历史登记，并在当前会话的文件列表中合并已打开记录。关联由 `sessionId + 来源路径` 历史索引提供，不伪造用户消息，也不把全文自动发给模型。已有解释/翻译与输入保护不变。未保存表单只在当前界面暂存，刷新/切换可能丢失。

已验证：真实会话工作区落盘、TXT 自动命名、Markdown 自定名与渲染、双击一次保存、重名后缀且原内容保留、草稿与请求数不变、刷新后当前会话重开、选段翻译来源与 sessionId 正确。宿主单测覆盖空白/超限/非法名/相对 cwd 拒绝及目录重定向保护；实际写入中断、权限拒绝、网络断线和保存中切换会话尚未做浏览器验收。
