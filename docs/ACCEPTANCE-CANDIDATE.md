## 固定范围与验收清单

本轮不增加新功能。用户在桌面 rc.5 重启后逐项核对：

- [ ] 现有会话打开 PDF/TXT/Markdown，左侧聊天和右侧原文独立滚动。
- [ ] 解释/翻译提交到当前会话一次，引用文字和来源正确；复制、询问 AI 正常。
- [ ] 已有草稿、附件或正在生成时不覆盖输入、不重复发送、不串会话。
- [ ] 文档历史按格式分组，多文件和两个会话分别记录，关闭和重启后可返回原文与对应消息。
- [ ] 粘贴默认 TXT，可选 Markdown；名称可改，保存到实际会话工作区，重名不覆盖。
- [ ] 保存粘贴文件不发送消息、不改聊天草稿；刷新后可重开并对选段交互。
- [ ] HTML、长文档和缩放后的恢复精度满足实际需要。
- [ ] 删除/归档会话、删除源文件、消息定位失败时提示明确，且不新建会话。
- [ ] 保存中切换会话、目录不可写及网络失败时，不误操作其他会话或静默丢失内容。
- [ ] 真实模型回答的翻译与解释质量符合使用需求。

历史自动测试的通过不代替上述桌面签收。EPUB 原生接入、OCR、全文双语排版、跨设备同步及手机布局不纳入本轮。
